Moje módy pro Luanti

Oficiální stránka pro bezpečné stažení mých rozšíření do hry Luanti. U každého módu si vyberte verzi pro Minetest Game nebo Mineclonia.

</> Zobrazit kompletní zdrojový kód na GitHubu

1. Spears Mod (Oštěpy)

Rozšiřuje bojový systém o vrhací a kontaktní oštěpy s delším dosahem.

Edice pro Minetest Game

Využívá standardní suroviny ze základní hry Minetest Game a jejích odvozenin.

⬇ Stáhnout pro Minetest Game
Soubor: spears-mtg.zip • v1.0.0

Edice pro Mineclonia

Plně přizpůsobeno pro hru Mineclonia včetně odpovídajících surovin, receptů a poškození.

⬇ Stáhnout pro Mineclonia
Soubor: spears-mineclonia.zip • v1.0.0

2. More Totems

Přidává do hry nové druhy totemů s unikátními ochrannými a podpůrnými schopnostmi.

Edice pro Minetest Game

Recepty a herní mechaniky totemů upravené pro klasický Minetest Game.

⬇ Stáhnout pro Minetest Game
Soubor: more-totems-mtg.zip • v1.0.0

Edice pro Mineclonia

Navrženo přímo pro Mineclonia s návazností na tamní systém totemů a surovin.

⬇ Stáhnout pro Mineclonia
Soubor: more-totems-mineclonia.zip • v1.0.0

3. Mód @a

Praktické rozšíření pro příkazy v chatu a správu světa pomocí selektorů (např. @a pro všechny hráče).

Edice pro Minetest Game

Kompatibilní se systémem příkazů a oprávnění v Minetest Game.

⬇ Stáhnout pro Minetest Game
Soubor: at-a-mtg.zip • v1.0.0

Edice pro Mineclonia

Přizpůsobeno pro příkazový systém a herní mechaniky v Mineclonia.

⬇ Stáhnout pro Mineclonia
Soubor: at-a-mineclonia.zip • v1.0.0

4. Armor HUD

Přidává do hry armor indikátor

Edice pro Minetest Game

Verze je stavena na mineclonia ale upravena pro minetest game takže by to mělo fungovat.

⬇ Stáhnout pro Minetest Game
Soubor: armor-hud-mtg.zip • v1.0.0

Edice pro Mineclonia

Navrženo přímo pro Mineclonia s návazností na tamní systém inventaře.

⬇ Stáhnout pro Mineclonia
Soubor: armor-hud-mineclonia.zip • v1.0.0
